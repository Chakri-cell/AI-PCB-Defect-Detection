# AI PCB Defect Detection and Classification

This project implements an AI-based system for detecting and classifying PCB defects using CNN and Streamlit.

## Features
- PCB defect detection using image difference
- CNN-based defect classification
- Streamlit web interface
- Export results as image and CSV

## Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- Streamlit

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
